---
title: "Activity log"
description: "A company-wide record of meaningful changes"
---

The activity log records leave requests, decisions, amendments, cancellations, role changes, assignments, policy updates and impersonation sessions. Entries keep the person's display name as it was when the action happened, so later profile edits do not rewrite history.

Search by person or action. Open a leave row on an employee record to see the audit events connected to that request.

<Note>
The activity log is for operational accountability. It does not expose authentication tokens, uploaded document contents or private system configuration.
</Note>
